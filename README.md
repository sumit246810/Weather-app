# Weather App

This is a simple weather app made using HTML, CSS and JavaScript.

## About

This project shows the current weather information for a city entered by the user. Weather data is fetched using a weather API.

## Features

* Search weather by city
* Shows temperature
* Shows weather condition
* Shows humidity
* Shows wind speed
* Simple and responsive design

## Technologies Used

* HTML
* CSS
* JavaScript
* Weather API

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a city name and check the weather.

## Project

This project was created for practice while learning JavaScript and working with APIs.
